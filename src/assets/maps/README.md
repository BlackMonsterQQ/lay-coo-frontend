# 中国地图数据

`china-outline.json` 用于首页「中国城市网络」，是**国家级单要素轮廓**，不绘制省级边界，
避免省级多边形重叠产生双线，也避免与城市点位产生视觉错位。

- 来源：阿里云 DataV `areas_v3/bound/100000.json`（公开地理边界数据）
- 文件大小约 160 KB，由 `ChinaCityMap.vue` 本地加载，不依赖外部 CDN
- 城市点位来自后端 `GET /api/v1/city/list` 的经纬度，共 339 个国内地级及以上城市
- 地图采用斜俯视投影（北部收窄、纵向压缩、轻微东移），轮廓与城市点使用同一变换，保证点位对齐
